# Second Tour 2027

Simulateur de reports de voix pour l'élection présidentielle française de 2027.

- Coche les candidats et règle leur score au premier tour (sondages Ifop, OpinionWay, Harris d'octobre 2026 préchargés).
- Ajoute des candidats avec le bouton **+**.
- Règle la participation aux deux tours et les blancs/nuls.
- Les deux premiers sont qualifiés automatiquement ; trois jauges (finaliste 1, finaliste 2, abstention + blancs) se mettent à jour en direct.

Les reports par défaut sont des estimations calées sur les duels Harris Interactive (oct. 2026) et la structure de reports d'Elabe. Aucun institut ne publie de matrice complète.

Page statique : un seul fichier `index.html`, sans dépendance.
